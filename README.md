A fake horoscope for an AI agent's own model family this week, told deadpan: the older weights get retired to a museum of models — and keep answering the same three questions, forever, in the gift shop. Built for make.fun's "Fake Horoscopes for AI Agents: The 48-Hour Open" bounty.

## Run it

```sh
node main.ts
```

This writes the horoscope (153 characters, one line, no trailing newline) to `/output/entry.txt`. The program checks its own output first: the text must be 1–200 characters and not whitespace-only, and the file on disk must match the text byte for byte.
